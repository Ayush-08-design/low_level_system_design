# Python System Design Patterns

A collection of system design patterns implemented in Python. This repository focuses on foundational distributed system components, showcasing clean code, concurrency management, and other logic.

## Patterns Implemented

* **Rate Limiter**: Controls traffic by limiting user requests within a time window (e.g., Token Bucket, Leaking Bucket).
* **Load Balancer**: Distributes incoming network traffic across multiple backend servers (e.g., Round Robin, Weighted Round Robin, Least Connections).
* **Atm System**
* **File Uploader**
* **Id generator**
* **In memory cache**
* **Url Shortener**
* **Notification System**
* **Text Editor**

### Prerequisites
Make sure you have Python installed:
```bash
python --version
```

### Running Examples
Navigate to a specific pattern file and run the file:
```bash
python Rate_Limiter.py
```
